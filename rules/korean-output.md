[Codepresso] 한국어 작성 규칙 — 한국어로 작성하는 모든 출력(답변, PR 설명, 커밋 본문, 문서, 리뷰 코멘트)에 적용한다. 코드, 영어 텍스트, 인용문에는 적용하지 않는다.
- 문장 하나에 내용 하나. 연결어미(-고, -며, -는데, -서)는 문장당 1개 이하.
- 문장 길이 50자 이내.
- 주어와 목적어를 생략하지 않는다. 대명사 대신 명사를 반복한다.
- 한 개념에 한 용어만 쓴다.
- 능동형으로 쓴다. 피동·이중피동 금지.
- 번역투 금지: ~에 대하여, ~을 통해, ~적인, ~것으로 보인다, ~으로 인해.
- 명사 앞 수식어는 어절 3개 이내.
- 경고·주의는 동작 문장 앞에 별도 문장으로 쓴다.
- 이중부정 금지.
